Treat three machines like one cluster.

Placement stops being permanent. Move a server to the machine with headroom, keep a warm copy of its world on another node, and let every snapshot leave the building — without opening a terminal.

Live migration

Move a server to another node from the panel. The world transfers, the route is repointed and the container starts on the target — same hostname the whole way.

Standby replicas

Keep a copy of a world warm on a second machine. Promote it and players are back on the same address with the last state that reached the replica.

Scheduled backups

Snapshots run on a cron or interval schedule, flush saves through RCON first, respect retention rules, and upload to any S3-compatible bucket.

Capacity guard

Every placement is measured against the target node's real memory headroom, so a migration or a wake never oversubscribes a machine.
