## Match your installation

Check the version or commit used to build your installation before following a guide. Later development changes may differ from the snapshot documented here.

The API reference describes the pinned schema. Your running panel remains the authority for the API it actually serves.

## Updating the pin

Maintainers update `docs/website-source.json` deliberately, review the guides and examples against that commit, and rebuild the complete website. The site build checks links and generates its API reference from the same source.

Repository pages linked from these docs use the pinned commit where an exact file version is needed.
