07 / EXPERIENCE

Design for the whole task.

Every screen must explain the current state and make the next step clear.

01

Show the real state

Separate empty, loading, stale and failed data. Unknown is not zero.

02

Make consequences clear

Name the resource and outcome before destructive or billable actions.

03

Help people recover

Preserve input and offer a useful next step when something fails.

08 / EXPERIENCE

Build and test for keyboard, assistive technology, zoom and different preferences.
