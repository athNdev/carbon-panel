## 13:25 UTC — Cluster multi-node RAM reporting, remote command routing, and metrics backoff
- What: Resolved zero-RAM node capacity reporting for dynamic nodes, routed commands on remote nodes directly via Docker exec, fixed remote SLP pings to node hosts, and added a 2-minute backoff cache for unsupported TPS candidate commands.
- Why: Servers on remote nodes were failing to start due to 0MB reported capacity, remote commands and SLP ping were failing over unreachable bridge IPs, and Fabric/modded servers without Paper TPS commands flooded logs.

## 14:05 UTC — Direct knock wake-on-connect and deep-sleep online status fix
- What: Conditioned Docker container 127.0.0.1 port isolation on global proxy enablement (`isProxyServer`), synchronized `ProxyEnabled` state across Docker client pool and proxy manager, reconfigured CT 108 container to `--net=host` mode, and updated server details/creation UI to differentiate proxied vs direct-port ingress.
- Why: When proxy was disabled, sleeping Minecraft servers appeared offline (connection refused) because Docker bridge mode blocked incoming direct knocks on port 25566, and containers were bound to 127.0.0.1 instead of 0.0.0.0 due to legacy auto-generated proxy hostnames.
